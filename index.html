Как получить данные Instagram

  1. Instagram → Профиль → ☰ → Центр аккаунтов.
  2. Ваша информация и разрешения → Скачать информацию (названия могут отличаться).
  3. Выбери Подписчики и подписки, формат JSON и период За всё время.
  4. Скачай ZIP в приложение «Файлы» на iPhone.
  5. Вернись сюда и нажми «Импорт ZIP / JSON / HTML».

Для определения отписок загрузи следующую полную выгрузку позже. Приложение сравнит её с предыдущей.
