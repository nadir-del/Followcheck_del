FollowCheck — личное PWA для iPhone
=================================

ЧТО ВНУТРИ
index.html — интерфейс
style.css — оформление
app.js — обработка выгрузок и история
jszip.min.js — локальная библиотека для ZIP (без обращения к CDN)
sw.js — офлайн-кэш
manifest.webmanifest и icons/ — установка на главный экран

КАК ОПУБЛИКОВАТЬ БЕЗ MAC С IPHONE
1. Распакуйте FollowCheck.zip в приложении «Файлы».
2. Создайте бесплатный аккаунт на github.com (если его нет).
3. Откройте github.com в Safari, создайте PUBLIC-репозиторий, например followcheck.
4. В репозитории выберите Add file → Upload files. Загрузите содержимое папки FollowCheck (файлы в корень репозитория, папку icons с картинками тоже). В мобильном Safari при необходимости выберите «Запросить настольный веб-сайт». Если загрузка папки недоступна, файлы можно загрузить по отдельности и создать icons/ отдельно.
5. В Settings → Pages → Build and deployment выберите Deploy from a branch, Branch: main, Folder: / (root), Save.
6. Подождите публикации. Адрес будет вида https://ВАШ-ЛОГИН.github.io/followcheck/ (реальный URL появится в Settings → Pages).
7. Откройте этот адрес в Safari → Поделиться → На экран «Домой» → Добавить.

ВАЖНО: PUBLIC-репозиторий содержит только код, не загружайте туда свои выгрузки Instagram. В приложении данные остаются в локальной базе Safari/установленного PWA. Если очистить данные сайта или удалить приложение, история может исчезнуть — периодически используйте «Экспортировать историю JSON» для резервной копии. Функция восстановления из такого файла в этой версии не реализована.

КАК ПОЛУЧИТЬ ДАННЫЕ
Instagram → Профиль → ☰ → Центр аккаунтов → Ваша информация и разрешения → Скачать информацию → Подписчики и подписки → За всё время → JSON → скачать ZIP.
Названия меню Instagram могут меняться. Приложение поддерживает стандартные followers_1.json, followers_2.json и following.json, а также HTML-экспорт с аналогичными именами. В ZIP должны присутствовать оба типа списков. Не загружайте архивы разных аккаунтов вместе.

КАК РАБОТАЕТ ИСТОРИЯ
При первом импорте создаётся снимок списков. При следующем отличающемся импорте создаётся новый снимок, и сравниваются две последние проверки. «Отписались» означает аккаунты, которые присутствовали в прошлой выгрузке, но отсутствуют в новой. Между проверками могли быть и другие изменения, поэтому это не история событий в реальном времени.

ПРИВАТНОСТЬ И ОГРАНИЧЕНИЯ
Нет логина в Instagram, пароля, сервера и отправки данных. Переход по ссылке «Профиль» открывает instagram.com и требует интернет. Для установки PWA и первого открытия необходим HTTPS-хостинг. Дальше основные функции доступны офлайн при сохранённом кэше. Приложение не тестировалось на конкретном устройстве пользователя; корректность зависит от формата выгрузки Instagram.
